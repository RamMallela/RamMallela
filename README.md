## What I'm building now

**[Jarvis](https://github.com/RamMallela/jarvis)** is a personal AI assistant that runs entirely on your own computer. It uses a local language model, keeps its memory in a local database, asks permission before changing anything, and logs every action. No cloud, no accounts, no data leaving the machine.

**Next up:** a benchmark of local language models on everyday laptops, and a private question-answering tool for your own notes.
